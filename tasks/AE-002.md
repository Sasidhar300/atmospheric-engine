## Work completed
Default demo, render, preview, and QC commands now create unique directories under `outputs/runs/`, with `video/`, `audio/`, `previews/`, and `qc/` created as needed. Default preview runs save a preview report alongside the video. The README documents the layout, CLI overrides, and the roles of `assets/`, `scenes/`, and `outputs/project/`.

## Decisions
Use a UTC timestamp, command name, and atomically allocated unique suffix for each default run. Explicit `--output` keeps the existing flat layout. The project store and legacy artifacts remain at their existing paths so earlier reports retain valid references. The old top-level plan, ledger export, and log have no tracked writers that target those filenames.
